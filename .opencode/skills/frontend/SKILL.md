# Frontend

Read `.github/instructions/frontend.instructions.md` before editing. Keep gateway contracts spec-driven, use TanStack Query for server data, and preserve accessibility, responsive behavior, and the existing visual language.

For visual changes, check desktop and narrow mobile layouts in the browser before reporting completion. Use the `playwright` MCP for repeatable interaction, accessibility snapshots, screenshots, and viewport checks. Use the `chrome-devtools` MCP when a live debugging session needs console errors, network failures, performance evidence, or DOM and CSS inspection. Do not use browser automation in place of the project's existing automated tests; run the available frontend validation commands as well.
